# 苹果式简约设计语言

来源：云办公 Office（F:\我的编程项目\375_Office全家桶）+ NJJ 裁剪工厂 + 个人网站，三者统一后的版本。

## 五条铁律

1. **只有一个主题色**：苹果蓝 `#0071e3`（深色 `#0a84ff`）。其余全部是中性灰。
2. **红 / 橙 / 绿只表达状态**（成功、警告、危险、未保存、星标），不做装饰。
3. **界面不用渐变**：按钮、图标、标题、Logo 一律纯色。只有功能性的渐变可以保留（滚动区边缘渐隐、用户可选的内容填充）。
4. **白底卡片、大圆角、无边框、极淡阴影**：卡片 20px 圆角，阴影 `0 1px 2px rgba(0,0,0,.04), 0 4px 16px rgba(0,0,0,.04)`；不用毛玻璃半透明。
5. **系统字体、标题字距收紧**：`-apple-system / PingFang SC / Microsoft YaHei`；标题 600 字重、`letter-spacing: -0.02em ~ -0.03em`；不用 800/900 粗黑体。

## 快速开始

1. 把 [tokens.css](tokens.css) 复制进项目，作为全局样式最先引入（纯 CSS 变量 + 基础组件，任何框架通用）。
2. 所有颜色、阴影、圆角只引用变量（`var(--primary)`、`var(--shadow-card)` …），不要在组件里写死十六进制色。
3. 组件按 [COMPONENTS.md](COMPONENTS.md) 的写法实现；用 Tailwind 的项目看其中的"Tailwind 对照"。
4. 需要"灵动"的首页/落地页，可加 [assets/fluid.js](assets/fluid.js) 单色流体背景（只在首页运行，离开即停）。

## 色板速查

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 `--bg` | `#f5f5f7` | `#000000` |
| 卡片 `--panel` | `#ffffff` | `#1c1c1e` |
| 灰底填充 `--fill`（次要按钮、分段控件底槽） | `#e8e8ed` | `#2c2c2e` |
| 正文 / 次要 / 弱 | `#1d1d1f` / `#6e6e73` / `#86868b` | `#f5f5f7` / `#a1a1a6` / `#8e8e93` |
| 细线 `--line` | `rgba(0,0,0,.08)` | `rgba(255,255,255,.1)` |
| 输入框描边 | `#d2d2d7` | `#48484a` |
| 主题蓝 / 悬停 / 浅底 | `#0071e3` / `#0077ed` / `#e8f2fd` | `#0a84ff` / `#409cff` / `rgba(10,132,255,.16)` |
| 成功 / 警告 / 危险 | `#248a3d` / `#c93400` / `#d70015` | `#30d158` / `#ff9f0a` / `#ff453a` |

多个模块需要区分时（如文字/表格/演示），只在**图标小方块**上用沉稳纯色：蓝 `#0071e3`、深绿 `#248a3d`、焦橙 `#c93400`；交互状态仍统一用主题蓝。

## 动效

- 曲线：弹性 `cubic-bezier(.34,1.56,.64,1)`（小图标、加号旋转、标签弹入），缓出 `cubic-bezier(.16,1,.3,1)`（卡片上浮、面板滑入）。
- 悬停：卡片上浮 2–3px 并换成 `--shadow-lift`；按钮按下 `scale(.97)`。
- 弹层：遮罩 `rgba(0,0,0,.3)` + `blur(3px)`，卡片 `scale(.94)→1`，0.18s。
- 必须支持 `prefers-reduced-motion: reduce`（tokens.css 已内置）。

## 动手前检查清单

- [ ] 页面里除主题蓝外没有第二个装饰色
- [ ] 搜索项目里的 `gradient`：只剩功能性用途
- [ ] 卡片无边框、20px 圆角、用 `--shadow-card`
- [ ] 主要按钮蓝色胶囊，次要按钮灰底胶囊，最多一个主要按钮
- [ ] 选中态 = 浅蓝底 + 蓝字（侧栏、页签）或白块浮在灰槽上（分段控件）
- [ ] 状态用"小圆点 + 文字"，不用整块色块
- [ ] 数字用 `font-variant-numeric: tabular-nums`
- [ ] 深色模式只靠切换变量完成，组件里没有写死浅色
- [ ] 窄屏（<760px）布局不横向溢出
